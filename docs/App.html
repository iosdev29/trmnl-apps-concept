Class

App

The base class of a TRMNL UI app.

TRMNL UI 1.0 · App API v1 · TRMNL X · TRMNL OG

Declaration

abstract class App extends TrmnlApp

Overview

Subclass App, implement body(), optionally implement glance(), and pass an instance to register(_:). App implements the App API lifecycle for you:

The firmware callsApp does
onLaunch(USER): the user opened the appdraws body() with a full refresh
onLaunch(RESUME) then onInput(event): a pressgives the action to the view with the focus; if a view used it, draws body() again
onLaunch(GLANCE): the playlist reached the appdraws glance() (or body()) with a full refresh
onSuspend(reason)nothing to do: state is already saved after every press

If no view uses a press (for example Next on a screen without a list), nothing is drawn and the e-paper keeps its picture: no refresh, no energy.

hello.ts
// Name: Hello
import { App, View, Layout, Title, Description, TitleBar, register } from "./trmnl-ui";
export { trmnl_event } from "./trmnl-ui";

class Hello extends App {
  body(): View {
    return Layout([
      Title("Hello, TRMNL"),
      Description("Your first app. It draws one screen and keeps it until you press a key."),
      TitleBar("Hello", "TRMNL UI"),
    ]);
  }
}

register(new Hello());

Topics

  • body(): the screen
  • glance(): the playlist screen
  • register(_:): run the app
