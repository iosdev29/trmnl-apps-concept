Function

Layout(_:)

Stacks views from top to bottom with the TRMNL margins.

TRMNL UI 1.0 · App API v1 · TRMNL X · TRMNL OG

Declaration

function Layout(children: View[]): View

Parameters

children
The views, from top to bottom.

Return Value

A view that fills the screen.

Discussion

  • Margins of 20 pt and a 10 pt gap between views.
  • Pinned views (TitleBar(_:_:)) go to the bottom edge first.
  • Views that fill (Reader(_:_:), Spacer()) share the space the others leave.
  • A press goes to the first child that uses it: see Handling input with focus.
spacer.ts
// Name: Status
import { App, View, Layout, Title, Description, Spacer, TitleBar, register } from "./trmnl-ui";
export { trmnl_event } from "./trmnl-ui";

class Status extends App {
  body(): View {
    return Layout([
      Title("All systems normal"),
      Spacer(),                                    // takes the free space
      Description("Last check 08:30. Next check in 15 minutes."),
      TitleBar("Status"),
    ]);
  }
}

register(new Status());

A Spacer pushes the description down to the title bar.
