List(_:_:)

Rows of items with one focused row.

TRMNL UI 1.0 · App API v1 · TRMNL X · TRMNL OG

Declaration

function List(items: string[], selection: State): ListView
onSelect(action: (row: i32) => void): ListView

Parameters

items
The rows, in order.
selection
The State that holds the focused row.
action
Called by Select with the focused row. A top-level function.

Discussion

PressWhat the list does
Nextmoves the focus down (wraps around)
Prevmoves the focus up (wraps around)
Selectcalls action(row)

Rows look like TRMNL plugin items: a number and the text, Inter semibold 18 pt, 44 pt high. The focused row is drawn inverted.

list.ts
// Name: Groceries
import { App, View, Layout, Title, Description, List, TitleBar, state, register } from "./trmnl-ui";
export { trmnl_event } from "./trmnl-ui";

const ITEMS: string[] = ["Oat milk", "Sourdough bread", "Apples", "Coffee beans"];
const focused = state("focused");
const picked = state("picked", -1);

function pick(row: i32): void { picked.value = row; }

class Groceries extends App {
  body(): View {
    const note = picked.value < 0 ? "Next and Prev move, Select picks." : "Picked: " + ITEMS[picked.value];
    return Layout([
      Title("Groceries"),
      Description(note),
      List(ITEMS, focused).onSelect(pick),
      TitleBar("Groceries", ITEMS.length.toString() + " items"),
    ]);
  }
}

register(new Groceries());

After one press of Next.

Lists do not scroll in v1: rows that do not fit are not drawn. Keep lists short or split them.
