Class

State

An integer that survives every wake.

TRMNL UI 1.0 · App API v1 · TRMNL X · TRMNL OG

Declaration

class State {
  get value(): i32
  set value(v: i32)
}

Overview

Create states with state(_:_:) at the top level of your file. Read .value in body() and write it in your actions; the next draw shows the change.

counter.ts
// Name: Tally
import { App, View, Layout, Value, List, TitleBar, state, register } from "./trmnl-ui";
export { trmnl_event } from "./trmnl-ui";

const count = state("count");      // survives every wake
const choice = state("choice");    // which row has the focus

function act(row: i32): void {
  if (row == 0) count.value = count.value + 1;
  else count.value = 0;
}

class Tally extends App {
  body(): View {
    return Layout([
      Value(count.value.toString(), "times"),
      List(["Add one", "Reset"], choice).onSelect(act),
      TitleBar("Tally"),
    ]);
  }
}

register(new Tally());

Count after two presses.

Where the value lives

In the app's KV under ui.<key>. It is kept through deep sleep, resets, relaunches and updates, and removed when the app is uninstalled. On the device KV lives in RTC memory and is written to flash now and then, so writing a state on every press costs nothing.
