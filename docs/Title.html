Title(_:)

The heading of a screen.

TRMNL UI 1.0 · App API v1 · TRMNL X · TRMNL OG

Declaration

function Title(text: string): View

Parameters

text
One line. Literata semibold, 28 pt.

Discussion

The title is part of the screen's identity: when its text changes, the next draw is a full refresh (see Screen updates and refresh). Put values that change on every press in a Value(_:_:) or a Description(_:) instead.

hello.ts
// Name: Hello
import { App, View, Layout, Title, Description, TitleBar, register } from "./trmnl-ui";
export { trmnl_event } from "./trmnl-ui";

class Hello extends App {
  body(): View {
    return Layout([
      Title("Hello, TRMNL"),
      Description("Your first app. It draws one screen and keeps it until you press a key."),
      TitleBar("Hello", "TRMNL UI"),
    ]);
  }
}

register(new Hello());
