The raw interface

What the WebAssembly module imports and exports, for any language.

App API v1 · TRMNL X · TRMNL OG

The SDK only wraps plain WebAssembly imports. A module must export trmnl_event, import its memory as env.memory, and import nothing outside these four modules (plus env.abort if its language needs it).

trmnl_event(kind, a, b, c)Meaning
kind 0launch, a = LaunchReason
kind 1input, a = action, b = gesture, c = source
kind 5suspend, a = SuspendReason
kind 6files changed: an upload ended, see Files
ModuleFunctions (all i32 unless noted)
trmnl_sys_v1device_model, screen_width, screen_height, screen_depth, inputs (bit 1 touchbar, bit 2 button), battery, now (f64), log(level, ptr, len), session_exit, buzzer(kind), app_version(out_ptr, max) → length
trmnl_kv_v1get(key_ptr, key_len, out_ptr, max) → length or -1, set(key_ptr, key_len, val_ptr, val_len) → 0 or -1, remove(key_ptr, key_len)
trmnl_ui_v1render(tree_ptr, tree_len, mode) → reader pages; see render(_:_:)
trmnl_files_v1count, name(i, out_ptr, max) → length, size(i), read(i, offset, out_ptr, max) → length or -1, remove(i) → 0 or -1, request_upload(), paginate(i) → count, -2 or -1, page_start(i, n) → offset or -1, page_of(i, offset) → page or -1, take_message(out_ptr, max) → length; see Files

Strings are a pointer and a length in the app's memory, encoded as UTF-8. Any language can build the JSON tree; the AssemblyScript SDK does it for you.
