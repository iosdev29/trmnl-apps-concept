KV

Small values that survive sleep, resets, relaunches and updates.

App API v1 · TRMNL X · TRMNL OG

LimitValue
Per value1 KB
Per app16 KB
Over the limitset returns false

KV is the app's memory between wakes; State is built on it (keys ui.<name>). On the device KV is one small file in the app's folder, rewritten after an event that changed it (atomically, so a crash keeps the previous values). Uninstalling the app removes it.
