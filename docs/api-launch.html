LaunchReason

Why the app was started.

App API v1 · TRMNL X · TRMNL OG

Declaration

namespace LaunchReason {
  const USER: i32 = 0
  const RESUME: i32 = 1
  const GLANCE: i32 = 2
}
ValueMeaningWhat TRMNL UI does
USERthe user opened the app: Select on its playlist screen, or the launcherrenders body() with a full refresh
RESUMEa wake after deep sleep; an input follows in the same wakegives the press to the focused view
GLANCEthe playlist reached the apprenders glance() with a full refresh

TRMNL UI's App handles all three; you only write body() and, if you like, glance().
