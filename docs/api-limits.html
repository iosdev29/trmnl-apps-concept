Limits and permissions

What the runtime enforces for every app.

App API v1 · TRMNL X · TRMNL OG
LimitValueWhen exceeded
Time per handler200 ms of app codethe app is stopped
Memory512 KB on the X, 64 KB on the OG (the device refuses a module declaring more)the app aborts
Package256 KB in this previewthe store refuses it
Refreshes1 per pressthe store refuses it
KV1 KB per value, 16 KB per appset returns false
Filesthe manifest's max_kb, at most 4 MBthe upload is refused
Crashes3 in a rowthe app is disabled

Memory is not freed during a wake (the instance lives for one press). Build long strings with whole-string operations, not one character at a time.

Always available: lifecycle, Device, Input, KV, the UI, Log, Session, Buzzer. Files need uploads in the manifest; sensors and cloud will need a permission too (see Planned modules).
