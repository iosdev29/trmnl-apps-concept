SuspendReason

Why the app is being closed.

App API v1 · TRMNL X · TRMNL OG

Declaration

namespace SuspendReason {
  const IDLE: i32 = 0
  const SESSION_CAP: i32 = 1
  const LOW_BATTERY: i32 = 2
  const USER_EXIT: i32 = 3
}
ValueMeaning
IDLEno press for the idle time from the manifest (10 minutes by default)
SESSION_CAPthe app ran for 60 minutes
LOW_BATTERYthe battery is low
USER_EXITHold middle, back to the playlist

State kept in State or KV is already saved, so there is nothing to do here.
