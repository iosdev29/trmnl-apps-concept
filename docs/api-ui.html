Function

render(_:_:)

Shows a TRMNL UI tree on the screen. The only way an app draws.

App API v1 · TRMNL X · TRMNL OG

Declaration

// trmnl_ui_v1
render(tree_ptr: i32, tree_len: i32, mode: i32): i32   // returns the page count of the first Reader

Discussion

TRMNL UI calls this once at the end of a handler; apps do not call it directly. The tree is JSON in UTF-8. The firmware lays it out, draws it in the TRMNL design and refreshes the panel.

NodeFields
layout, rowc: children
title, descs: text
valuev: value, s: label
progressv: done, of: total
heatmapv: cells, r: rows, c: columns
listitems: texts, sel: focused row
readers: text, page: page
bars: title, i: instance
spacer, dividernone
modePanel
0 AUTOpartial, with a full refresh every 8
1 PARTIALpartial
2 FULLfull refresh

Unknown node types are ignored, so a newer app on an older firmware degrades instead of failing.
