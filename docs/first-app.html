Building your first app

Write an app, build it to WebAssembly, and run it on a simulated TRMNL.

TRMNL UI 1.0 · App API v1 · TRMNL X · TRMNL OG

1. Start with one screen

Create app.ts. Import the views from ./trmnl-ui, subclass App, and return the screen from body().

hello.ts
// Name: Hello
import { App, View, Layout, Title, Description, TitleBar, register } from "./trmnl-ui";
export { trmnl_event } from "./trmnl-ui";

class Hello extends App {
  body(): View {
    return Layout([
      Title("Hello, TRMNL"),
      Description("Your first app. It draws one screen and keeps it until you press a key."),
      TitleBar("Hello", "TRMNL UI"),
    ]);
  }
}

register(new Hello());

Two lines are always there: register(new Hello()) tells the framework which app to run, and export { trmnl_event } from "./trmnl" exposes the one function the firmware calls on every wake.

Hello on the X and the OG.

2. Build

In the dashboard, open Apps → Developer and press Build. On your own machine, use the AssemblyScript compiler with the same flags:

asc app.ts --outFile app.wasm --runtime stub --importMemory --initialMemory 1 --maximumMemory 8 -O3 --noAssert

The result is app.wasm: your code plus a list of the App API functions it may call, and nothing else.

3. Add state and a list

Keep values in a State so they survive the deep sleep between presses, and put the choices in a List(_:_:). The list moves its focus on Next and Prev and calls your function on Select.

counter.ts
// Name: Tally
import { App, View, Layout, Value, List, TitleBar, state, register } from "./trmnl-ui";
export { trmnl_event } from "./trmnl-ui";

const count = state("count");      // survives every wake
const choice = state("choice");    // which row has the focus

function act(row: i32): void {
  if (row == 0) count.value = count.value + 1;
  else count.value = 0;
}

class Tally extends App {
  body(): View {
    return Layout([
      Value(count.value.toString(), "times"),
      List(["Add one", "Reset"], choice).onSelect(act),
      TitleBar("Tally"),
    ]);
  }
}

register(new Tally());

After two presses of Select on Add one.

4. Try it

Press Prev, Select and Next under the simulator, or use ←, Enter and →. Each press is logged as one wake: onLaunch(RESUME) → onInput(SELECT, tap middle, touchbar), with its time and memory.
