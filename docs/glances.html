Glances in the playlist

How an app sits among plugins, opens on Select and returns on Hold.

TRMNL UI 1.0 · App API v1 · TRMNL X · TRMNL OG
  • The playlist shows plugins and the glances of installed apps, on its usual timer.
  • Select on a glance opens the app at its current state.
  • Hold middle in the app returns to the same playlist item, with an updated glance.
  • On the X, Hold middle on any playlist screen opens a launcher with all installed apps.
  • In the dashboard, each installed app has an In playlist switch.
