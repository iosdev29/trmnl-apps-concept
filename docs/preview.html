preview()

Mock data for the Developer tab, like a SwiftUI preview.

TRMNL UI 1.0 · App API v1 · TRMNL X · TRMNL OG

Declaration

preview(): void

Override it to fill State and KV with plausible values, so a screen can be seen in a realistic state without pressing through it. In the Developer tab every Run of an app with a preview starts from empty preview data, calls preview() and then opens the app; the Preview button does it again. Preview data is kept apart from the app's real saved values. A device never calls it.

preview(): void {
  KV.setString("h.0", "0110111011110111");  // the keys and format the app writes
  KV.setInt("h.sel", 0);
}

Write the data in exactly the format the app reads, and keep it deterministic so every preview looks the same.
