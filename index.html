Real apps on a TRMNL

Interactive apps that run on the X itself: a press wakes it, the app answers, and it sleeps again. Games and readers built in the browser, installed like a plugin, and unable to break the device or drain its battery.

Why this stack

A small chip that sleeps most of the time, running code we did not write. Four ways to do it.

OptionWhy
Server rendering
today's plugins		Every press needs Wi‑Fi: 690 mC against 80 mC for an app press. No offline use

C in the firmware		No isolation: one bad app can brick the device, drain it or read the Wi‑Fi password
Script engine
Lua, MicroPython, JS		A bigger runtime and more RAM, garbage-collection pauses, one language, and it still needs its own sandbox
WebAssembly
on WAMR, our choice		A sealed box by design, any language that compiles to it. Apps of about 12 KB, every memory access checked, only App API v1 to call. An interpreter today, compiled per chip later

  • Apps describe screens, TRMNL UI draws them no drawing API

An app can't break the device

We never trust the app. Every limit is enforced outside it.

MemoryEvery access is checked: an app can only touch its own memory, capped by the firmware at 512 KB. On the X it lives in external RAM, so an app can't eat into what the firmware needs.
TimeAn event should take under 200 ms. One that runs past 5 s restarts the device into the normal TRMNL. Open: three crashes in a row should turn the app off.
ReachNo network, no drawing, no files outside its own folder. Anything else fails to load.
Storage1 KB per value and 16 KB of saved data per app, uploads capped per app. Flash is written once per burst.
ExitHolding the middle of the touchbar always leaves. No app can catch it.

The App Library, or just your devices

The same .tapp either way, like public and private plugins today.

App Library

Reviewed and signed by TRMNL

  • Found in Discover, installed to any device
  • Updates arrive at the next check-in
  • A bad version can be pulled

Private

Yours, unverified

  • "Install on my X" from the Developer tab
  • Runs only on devices you own
  • Same sandbox, same limits
